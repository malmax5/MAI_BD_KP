## 🏢 О проекте

Warehouse Management System (WMS) — это система для автоматизации управления складскими операциями, включая учёт товаров, управление заказами, инвентаризацию и отслеживание перемещений.

**Основные возможности:**
- Управление товарами и категориями
- Контроль складских ячеек и зон хранения
- Обработка заказов клиентов
- Управление поставщиками и партиями товаров
- Инвентаризация и аудит
- Ролевая модель доступа
- RESTful API
